# C++ Portfolio

Добро пожаловать в мой репозиторий.

Здесь собраны мои проекты и учебные работы по C++, подготовленные в рамках обучения и практики.

Все основные проекты, исходный код, лабораторные работы, CMake-конфигурации и тесты находятся в ветке `projects`.

Если вы проверяете этот репозиторий для стажировки, пожалуйста, перейдите в ветку `projects`:
- там находится полный набор работ
- там можно посмотреть структуру проектов
- там размещён код и описание реализованных задач

Спасибо за внимание.
