# C++ Portfolio

Репозиторий с моими лабораторными работами по C++, собранными в одном месте как учебное портфолио. ## Лабораторные работы

### [Lab 1](./labs/lab1) — Шаблонизатор
Консольная утилита для генерации текстового документа по шаблону и файлу данных. Реализованы чтение файлов, парсинг аргументов командной строки, поиск и подстановка placeholders, обработка ошибок и работа со строками в стиле C без `std::string`.

### [Lab 2](./labs/lab2) — Пользовательский тип `int2025_t`
Реализация собственного целочисленного типа фиксированной длины с поддержкой конвертации, арифметики, сравнений и вывода в поток. Работа показывает понимание представления чисел в памяти, побитовых операций и перегрузки операторов.

### [Lab 3](./labs/lab3) — Библиотека парсинга аргументов
Библиотека для разбора аргументов командной строки с поддержкой флагов, позиционных и именованных параметров, а также разных типов значений. Основной акцент сделан на проектировании интерфейса и управлении памятью без стандартных контейнеров и строк.

### [Lab 4](./labs/lab4) — Архиватор `HamArc`
Консольный архиватор без сжатия с использованием кодов Хэмминга для помехоустойчивого хранения данных. Поддерживаются создание архива, список файлов, извлечение, добавление, удаление и объединение архивов.

### [Lab 6](./labs/lab6) — STL-совместимый `circular_buffer`
Шаблонный контейнер циклического буфера с аллокатором, итераторами произвольного доступа и интерфейсом, близким к STL. Эта работа хорошо показывает понимание контейнеров, шаблонов, итераторов и требований к пользовательским структурам данных.

### [Lab 7](./labs/lab7) — Поиск маршрутов через Yandex API
Консольное приложение для поиска маршрутов между городами с использованием HTTP-запросов, JSON и внешних библиотек. В проекте реализованы интерактивный режим, кэширование ответов и базовая обработка ошибок при работе с внешним сервисом.

### [Lab 8](./labs/lab8) — Библиотека адаптеров обработки данных
Библиотека адаптеров для обработки данных в стиле pipeline с ленивыми преобразованиями. Включает фильтрацию, трансформацию, чтение файлов, split, join, агрегацию и сбор результатов в контейнеры.
