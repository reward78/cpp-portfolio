# Algorithms

В этой папке собраны мои базовые реализации алгоритмов и структур данных на C++.
Это тренировочные задачи, которые я использовал для практики алгоритмического мышления, работы со структурами данных и закрепления стандартных подходов к решению типовых задач.

## Что здесь есть

- графовые алгоритмы
- динамическое программирование
- базовые алгоритмы сортировки

## Список реализаций

- [sorting/merge_sort.cpp](./sorting/merge_sort.cpp) — сортировка слиянием
- [graphs/dijkstra.cpp](./graphs/dijkstra.cpp) — алгоритм Дейкстры с `std::set`
- [graphs/floyd_warshall.cpp](./graphs/floyd_warshall.cpp) — алгоритм Флойда-Уоршелла
- [graphs/bellman_ford.cpp](./graphs/bellman_ford.cpp) — алгоритм Беллмана-Форда
- [dp/hamiltonian_path.cpp](./dp/hamiltonian_path.cpp) — поиск гамильтонова пути через DP по подмножествам

Все файлы оформлены как небольшие самостоятельные консольные программы с чтением входных данных из `stdin`.
